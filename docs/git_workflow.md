# Git Workflow

## Repository setup

```bash
cd mnist-generative-models-lab
git init
git branch -M main
git add .
git commit -m "Initial MNIST generative models lab"
```

Remote (when ready):

```bash
git remote add origin https://github.com/jt-09/mnist-generative-models-lab.git
git push -u origin main
```

## Branch strategy

- **`main`** — polished portfolio state
- **Feature branches** — one milestone per model family (see `docs/branch_pr_plan.md`)
- **Merge method** — squash merge recommended

## Recommended branch sequence

1. `setup/repo-structure`
2. `analysis/eda`
3. `model/manual-knn`
4. `model/manual-logistic-regression`
5. `model/manual-mlp`
6. `model/cnn-baseline`
7. `model/model-comparison`
8. `model/vae`
9. `model/ddpm`
10. `model/dcgan`
11. `model/latent-diffusion`
12. `docs/learning-roadmap`
13. `docs/report-plan`

## Creating a feature branch

```bash
git checkout main
git pull
git checkout -b model/manual-knn
# add notebook + any docs
git add notebooks/manual_knn.ipynb
git commit -m "Add manual KNN notebook with GPU batched implementation"
git push -u origin model/manual-knn
gh pr create --title "Manual KNN" --body "Adds manual_knn.ipynb. Metric: 0.9705 from saved outputs."
```

## Commit message style

- Imperative mood: "Add VAE notebook", "Document generative metrics"
- Reference metrics in body when adding notebooks
- Do not commit `training_results/`, `*.pth`, or `latent_data/`

## What never to commit

| Pattern | Reason |
|---------|--------|
| `training_results/` | Regenerated by `vae.ipynb` |
| `latent_data/` | Regenerated by latent-diff notebook |
| `*.pth`, `*.pkl` | Model checkpoints |
| `venv/` | Local environment |
| `.ipynb_checkpoints/` | Jupyter temp |

## PR review flow

1. Author runs smoke tests (`docs/smoke_tests.md`)
2. Reviewer checks `docs/review_checklist.md`
3. Squash merge to `main`
4. Delete feature branch

## Monorepo relationship

This repo was split from `ml-proj/mnist/`. The monorepo remains as historical archive. Copy is one-way; do not delete monorepo source.

## Tags (optional)

After all 13 PRs merge:

```bash
git tag -a v1.0.0 -m "Complete MNIST lab: classification + generative tracks"
git push origin v1.0.0
```

## Direct-to-main alternative

For a solo portfolio push, a single commit on `main` is acceptable. The branch plan documents evolution for interview narrative without requiring 13 actual PRs.
